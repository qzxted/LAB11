# Лабораторна робота №11


## Структура проєкту

* src/zavd1.cpp, zavd2.cpp, zavd3.cpp, zavd4.cpp, zavd5.cpp, zavd6.cpp.
* CMakeLists.txt


## Збірка та запуск

1. Відкрийте папку проєкту у Visual Studio з увімкненою підтримкою CMake.
2. Оберіть пресет x64-windows і виконайте повну збірку.
3. Запустіть зібрані exe:
  * zavd1.exe
  * zavd2.exe
  * zavd3.exe
  * zavd4.exe
  * zavd5.exe
  * zavd6.exe
